# subquo

subquo is a project to read subscription quota for Claude Code, Codex, and OpenCode Go.
This repository contains the account list format and the first checks against existing logins.
There is no quota reader to install yet.

## Where things are

- [Account list](docs/accounts.md): The private `accounts.toml` format and a copyable example.
- [Stage 1 findings](docs/stage-1-findings.md): What the login checks show about expiry, setup tokens, and renewal.
